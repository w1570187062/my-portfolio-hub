资产页卡片光斑 · 处理方案

19 个同角度光斑 → 语义化 vs. 交互化
01

为什么会疲劳

不是渐变太亮，是同一种装饰在视野里重复了 19 次。装饰一旦重复，就从「强调」降级成「纹理」——所有卡都被同等强调，等于没有一张被强调。

同角度 · 同颜色 · 同强度 → 规律点阵

1四层卡共用同一段 CSS radial-gradient(122% 94% at 100% 0%, …) 被摘要卡、账户卡、总览折叠卡、持仓分组卡同时引用，位置和角度完全一致，网格里排成阵列。
2摘要卡已经有两个色彩中心 左侧 4px 语义色条（净资产金 / 负债灰蓝 / HK 靛 / US 蓝绿）已经在传递信息，右上角却又压一个统一的品牌金光斑 —— 一张卡两个色彩中心，一个有意义、一个纯装饰，互相抢。
3账户卡的色彩已经有归属 品牌 logo chip + 地域 badge 已经给了颜色，卡面再叠一层同色晕，只是把同一件事说了两遍。
02

三个处理方向

关键不是「留还是删」，而是把色彩从装饰通道挪回信息通道，再用交互态承接质感。

03

取舍

方案解决重复解决单调色彩是否承载信息改动面
A · 语义化 + 交互化✓ 每卡异色，不再阵列✓ 悬停有质感反馈✓ 摘要卡光色=语义色仅 CSS，--card-glow 拆两支
B · 顶部细线△ 变成条带阵列△ 靠精密感✗ 仍是统一色4 处卡片 + 日间核对
C · 全静默✓ 彻底✗ 偏空△ 只靠色条4 处，删代码
结论

选 A。它同时回答了你问的两件事：疲劳来自「19 个一模一样的色斑」，所以让摘要卡的色斑改用自己的语义色（不再是同一个金）；单调来自「没有任何反馈」，所以让账户卡的质感从静态装饰变成悬停反馈 —— 静止时干净，操作时才有回应。
容器级大卡（资产总览折叠卡、持仓分组卡）保留原光斑不动：它们每屏只有 1–2 个，是页面的空间锚点，重复条件不成立。

落地口径 · 只动 style.css，三处
/* 1. 摘要卡角光改用各自的语义色（app.js 早已注入 --card-accent，只是没用上） */
.as-card {
  background-image: radial-gradient(122% 94% at 100% 0%,
    color-mix(in srgb, var(--card-accent) 8%, transparent) 0%, transparent 58%);
}

/* 2. 账户卡：静息无光，悬停淡入（background-image 不可过渡，用伪元素承载） */
.src-card { background-image: none; }
.src-card::before {
  content: ""; position: absolute; inset: 0; border-radius: inherit; pointer-events: none;
  background-image: var(--card-glow);
  opacity: 0; transition: opacity .28s var(--e);
}
.src-card:hover::before { opacity: 1; }

/* 3. .summary.collapsible / .holdings-group：维持原样，不改 */
