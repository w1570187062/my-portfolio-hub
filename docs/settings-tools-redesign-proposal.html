核心问题：设置页把「风险偏好 / 推送策略 / AI」三个互不从属的功能塞进一个名为"通知"的卡片（标题与内容错位）；工具页把 5 个计算器平铺在"工具"标题下、没有次级归类。下方左右对照——左为当前，右为方案。

当前痛点：语义错位 / 信息平铺无层级 方案：按语义拆分组 + 次级归类 + 舒适最大宽度
